# Drafts

Posts here are NEVER built by `npm run build` / `npm run deploy`. To publish a draft: review and edit it, set the real
`date`, and move it to `content/blog/`. Preview all drafts locally with `npm run preview` (they get a DRAFT banner and noindex).
Each draft names its source post in `source:`; the Telegram text is the owner's, the English version is an adaptation.
